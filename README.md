# GreenWave Audio AI & TinyML — Emergency Siren Detection

A reproducible research and deployment-handover repository for the GreenWave TechLabs
Audio AI & TinyML emergency-siren detection internship project.

## Project

The final validated release documented during the internship uses:

- **Task:** binary emergency-siren detection
- **Classes:** `0 = NON_SIREN`, `1 = SIREN`
- **Target:** ESP32-S3
- **Model:** Depthwise Separable CNN (DS-CNN)
- **Audio:** mono, 16 kHz, fixed 2.0 s / 32,000 samples
- **Feature:** 40-bin Log-Mel spectrogram
- **Model input:** `[1, 40, 161, 1]`
- **Deployment format:** fully integer INT8 TensorFlow Lite
- **Runtime target:** TensorFlow Lite Micro

The internship record distinguishes **validated model/handover work** from **actual
on-device hardware measurements**. ESP32-S3 tensor-arena usage, device latency,
firmware compilation, and real hardware behaviour were not measured in the documented
Phase 6 material.

## Validated results

| Stage | Accuracy |
|---|---:|
| Keras reference | 96.5636% |
| FP32 TensorFlow Lite | 96.5636% |
| INT8 TensorFlow Lite | 95.8763% |

- INT8 accuracy change: **0.6873 percentage points**
- FP32 TFLite size: **25.59 KB**
- INT8 TFLite size: **17.79 KB**
- Size reduction: **30.47%**
- Golden test vectors: **20**

## Frozen preprocessing contract

1. Convert to mono.
2. Resample to 16,000 Hz.
3. Make every sample exactly 2 seconds / 32,000 samples:
   - truncate longer audio
   - zero-pad shorter audio
4. Peak normalization.
5. DC-offset removal.
6. 4th-order Butterworth high-pass at 100 Hz.
7. 4th-order Butterworth low-pass at 7,500 Hz.
8. Peak normalization again.
9. STFT:
   - FFT size: 400
   - window: 400 samples
   - hop: 200 samples
   - Hamming window
   - `center=True`
10. 40 Mel bands, 0–8,000 Hz.
11. Convert Mel power to dB using `ref=max`.
12. Global normalization using:
   - mean = `-34.235347747802734`
   - std = `15.560243606567383`
13. Add channel dimension → `[40, 161, 1]`.
14. Add batch dimension for inference → `[1, 40, 161, 1]`.


## Dataset layout

The training scripts expect:

```text
data/audio/
├── NON_SIREN/
│   ├── *.wav
│   └── ...
└── SIREN/
    ├── *.wav
```

Do not commit copyrighted or restricted audio datasets into the repository. Keep the
dataset locally and document its source and license.

## Important reproducibility note

The repository source implements the documented frozen preprocessing contract.
The exact historical trained `.keras`/`.tflite` binaries and the original audio/golden
vector payloads are not regenerated by this repository unless the corresponding
project artifacts are supplied locally.

This avoids pretending that a newly trained model is byte-identical to the validated
internship release.
